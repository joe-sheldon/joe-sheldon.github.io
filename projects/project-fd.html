Foolish Division

Project Overview

This is meant to be an open source alternative to Splitwise. The backend is Django/DRF and Postgres; the frontend in ReactJS. Deployed locally (through cloudflare tunnel to my Portainer instance) or on Render. The backend is *mostly* done, however security enhancements and finishing touches on the permission model need to be completed before it is ready for use. The frontend is currently in work.
